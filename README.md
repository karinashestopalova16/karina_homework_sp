# Виджет банковских операций клиента

## Описание
Виджет банковских операций клиента - приложение для работы с данными банковских операций клиента. Позволяет маскировать данные счета или карты, фильтровать операции по статусу или дате свершения.

## Структура

`masks.py` — функции для маскировки номеров банковских карт и счетов.

`processing.py` — функции для фильтрации операций по статусу и сортировки операций по дате.

`widget.py` — функции для обработки и форматирования данных банковских операций.

`generators.py` — функции-генераторы для работы с банковскими операциями и генерации номеров карт.

## Использование
Модуль `masks`

Функции модуля masks используются для маскировки номеров карт и счетов.

Пример:
```
get_mask_card_number("1234567812345678")
>>> 1234 56** **** 5678
get_mask_account("12345678901234567890")
>>> **7890
```

Модуль `processing`

Функция `filter_by_state` используется для фильтрации банковских операций по статусу.

Пример:
```
filter_by_state(
    [
        {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
        {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
        {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},
    ]
)
```

Функция `sort_by_date` используется для сортировки списка операций по дате.

Пример:
```
sort_by_date(
    [
        {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
        {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
        {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},
    ]
)
```

Модуль `widget`

Модуль `widget` используется для обработки данных банковской операции и форматирования даты и информации о карте или счёте.

Пример:
```
mask_account_card("Visa Platinum 1234567812345678")
>>> Visa Platinum 1234 56** **** 5678
get_date("2018-07-11T02:26:18.671407")
>>> 11.07.2018
```

Модуль `generators`

Функция `filter_by_currency` используется для фильтрации банковских операций по валюте.

Пример:
```
filter_by_currency(transactions, "USD")
```

Функция `transaction_descriptions` используется для последовательного получения описаний банковских операций.

Пример:
```
transaction_descriptions(transactions)
```

Генератор `card_number_generator` используется для генерации номеров банковских карт в формате XXXX XXXX XXXX XXXX.

Пример:
```
card_number_generator(1, 10)
```

## Тестирование
Для тестирования используется `pytest`.

Для запуска всех тестов используйте команду:
```
poetry run pytest
```

Для проверки покрытия кода используйте команду:
```
poetry run pytest --cov
```

Для создания HTML-отчёта о покрытии:
```
poetry run pytest --cov --cov-report=html
```

HTML-отчёт сохраняется в папке `htmlcov`.
