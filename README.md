# Виджет банковских операций клиента

## Описание
Виджет банковских операций клиента - приложение для работы с данными банковских операций клиента. Позволяет маскировать данные счета или карты, фильтровать операции по статусу или дате свершения.

## Установка

1. Клонируйте репозиторий
```
git clone git@github.com:karinashestopalova16/karina_homework_sp.git
```

2. Установите зависимости
```
poetry install
```

## Использование
1. Функция `filter_by_state` используется для фильтрации по статусу банковской операции.

Пример вызова:
```python
filter_by_state([
       {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
       {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
       {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
       {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
   ])
```

2. Функция `sort_by_date` используется для сортировки списка операций по дате совершения.

Пример вызова:
```python
sort_by_date([
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
])
```
